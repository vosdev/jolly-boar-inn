# Progress

Open work is GitHub issues, grouped in milestones on the
[project board](https://github.com/users/vosdev/projects/3), each issue with its spec, accept
criteria and dependencies. This file keeps the milestones; the version is in [VERSION](../VERSION), and
loose ideas in [IDEAS.md](IDEAS.md).

## Phase 0 and Phase 1

Done: rooms, joins, the websocket, scoring, restart recovery, the client, the containers and a
30-bot load test, with More or Less.

## [Phase 2](https://github.com/vosdev/jolly-boar-inn/milestone/1) — Complete the base game

Done: the mode/type split, credit and its three scorings, the client presentation layer, The Price
is Right, Guess the Examine, multiple choice, closest number, free text, random events, the wiki's
rules, six options at most, and the design track through the stage and its hosts. The rest is the
milestone.
