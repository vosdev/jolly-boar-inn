# RuneScape Quill 8

`RuneScape-Quill-8.ttf` is the in-game dialogue font, from [RuneStar/fonts](https://github.com/RuneStar/fonts)
release 1.103-0 (CC0 for their packaging). The glyphs are © Jagex Ltd and used under Jagex's fan content
policy, like the rest of the game art; the README's license section covers it. It is drawn at 16px and
used on the clue scroll only.
