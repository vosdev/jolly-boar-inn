# Security policy

Report a vulnerability privately through
[GitHub's advisory form](https://github.com/vosdev/jolly-boar-inn/security/advisories/new), not in a
public issue. Include what you did, what happened and which version the footer shows.

Only the latest release is supported: while the version starts with 0, fixes land on `main` and are
not backported.

A flaw in this code is in scope wherever the inn is hosted. A problem with one selfhosted instance's
setup (its domain, proxy or `ADMIN_TOKEN`) goes to whoever runs it.
